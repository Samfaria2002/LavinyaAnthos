# Protótipo — Exposição FLORESCER

Protótipo navegável com três áreas:

- Início e apresentação da exposição
- Galeria de quadros/prévias
- Formulário de confirmação de presença

## Executar localmente

Requer Node.js 22 ou superior.

```bash
npm install
npm run dev
```

O formulário demonstra o fluxo e o estado de sucesso, mas não envia os dados para um servidor.
